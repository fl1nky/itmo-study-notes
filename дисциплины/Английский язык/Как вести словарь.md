# Словарь, из которого получается разговор

## Одна запись — один смысл в ситуации

Записывай слово вместе с действием, объектом и своей репликой. В новой теме опорой служит маленькая рабочая сцена: какая проблема возникла, что ты хочешь уточнить и что предлагаешь сделать.

### Заполненный пример

| Поле | Моя запись |
|---|---|
| Сцена | После выпуска версии сервис перестал отвечать |
| Выражение | **roll back** |
| Смысл здесь | Откатить релиз к предыдущей версии |
| Готовая связка | **roll back a release** |
| Формы | roll — rolled — rolled |
| Объект и местоимение | roll the release back → **roll it back** |
| Моя реплика | **We rolled out the update this morning. Now we need to roll it back.** |
| Близкая форма | **rollback** — существительное: **perform a rollback** |
| Когда использовать | Короткое сообщение команде о проблеме релиза |
| Как проверить значение | [Kubernetes: откат Deployment](https://kubernetes.io/docs/concepts/workloads/controllers/deployment/) и [Cambridge: rollback](https://dictionary.cambridge.org/us/dictionary/english/rollback) |

**Вопрос для себя:** «Обновление сломало сервис. Как предложишь его откатить?»

## Как заполнить новую запись

1. Скопируй [шаблон записи](<Шаблоны/Словарная запись.md>). Для большой темы возьми [шаблон сцены](<Шаблоны/Тематическая сцена.md>).
2. Выбери один смысл, с которым действительно встретился в задаче, документации, видео или разговоре. Запиши ссылку и короткий контекст.
3. Найди частое сочетание: **reproduce a bug**, **grant permission**, **give an estimate**. Проверь управление и произношение по словарю.
4. Для фразового глагола запиши формы и схему с объектом; затем сделай вариант с **it / them / me**.
5. Придумай свою реплику, которую мог бы сказать одногруппнику или коллеге. По ней составь вопрос без подсказки.

## Повторять через действие

- Закрой перевод и объясни смысл по-русски или простым английским.
- Восстанови слово в предложении, затем скажи целую реплику.
- Замени детали примера на свою задачу и разыграй 2–4 реплики.
- Отметь честно: **узнаю → вспоминаю → использую**. Это ориентир для себя, не оценка экзамена.

Можно начать с повторов на следующий день, через 3 и через 7 дней, а затем подстроить интервалы. Если не вспомнил — вернись раньше. Это удобный стартовый ритм, а не универсально оптимальное расписание. Автоматических событий в календаре нет.

## Небольшая запись — конкретный результат

На одну запись достаточно одного значения, одной связки, одного личного предложения и одного вопроса для себя. Другие значения добавляй отдельной записью, когда они встретятся.
