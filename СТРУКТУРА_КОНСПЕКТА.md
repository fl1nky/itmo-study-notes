# Структура конспекта занятия

Используй этот порядок для каждого нового `конспект.md` в каталоге дисциплины.

1. **Тема** — первая строка файла, заголовок `# ...`. Название должно совпадать с темой в папке и индексе предмета.
2. **Дата занятия** — сразу под темой, формат `ГГГГ-ММ-ДД`. Если дата взята только из чужой записи или не подтверждена расписанием, укажи это рядом с датой. Не придумывай дату.
3. **Конспект** — раздел `## Конспект` с последовательными подразделами по содержанию занятия. Объясняй определения своими словами, записывай точные формулы, поясняй обозначения и давай разобранные примеры. Не ограничивайся списком терминов. Укажи исходник в начале раздела; короткие дословные цитаты сопровождай страницей или таймкодом. Неразборчивые места отмечай прямо в соответствующем подразделе.
4. **На что обратить внимание** — выделяй внутри конспекта блоком `> **Обратите внимание.** ...` сразу после сложного правила или примера. Отмечай типичные ошибки, условия применимости, различия похожих понятий и то, что нужно запомнить.
5. **Вопросы для самопроверки** — последний раздел файла. Вопросы должны проверять понимание определений и умение применить их к примеру. Краткие ответы можно скрыть под `<details>`, но после этого раздела других разделов не добавляй.

Снимки доски, аудио, полные расшифровки и черновики держи только в игнорируемой Git папке `входящие/`. На GitHub публикуй проверенный Markdown-конспект. Не выдавай слова однокурсника за речь преподавателя и не превращай сомнительные записи в уверенные утверждения.
