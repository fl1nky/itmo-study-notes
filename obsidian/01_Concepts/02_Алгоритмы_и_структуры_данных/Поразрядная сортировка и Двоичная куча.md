# ⚡ Поразрядная сортировка (Radix Sort) и Двоичная куча

> Конспект пары: некомпараторная сортировка разрядами (LSD / MSD) и компактная структура данных «Двоичная куча» на массиве.

---

## 🔢 1. Radix Sort (Цифровая сортировка)

Сортировка за **$O(d \cdot (n + b))$**, где $d$ — число разрядов, $b$ — основание системы счисления ($10$, $256$ и т.д.). Обходит нижнюю границу сравнений $O(n \log n)$.

```text
               Число: [ 4 ] [ 7 ] [ 2 ]
                        ▲           ▲
        MSD ────────────┘           └──────────── LSD
 (старшие ──► младшие)                     (младшие ──► старшие)
```

### Главные отличия LSD и MSD:

| Параметр | **LSD** (Least Significant Digit) | **MSD** (Most Significant Digit) |
|---|---|---|
| **Направление** | От **младших** разрядов к старшим ($0 \to d-1$). | От **старших** разрядов к младшим ($d-1 \to 0$). |
| **Принцип** | Итеративный проход по всему массиву. | Рекурсивное разделение по корзинам (Divide & Conquer). |
| **Условие** | **Обязательно устойчивая (Stable)** подсортировка (Counting Sort). | Для корректности MSD устойчивость не обязательна; для устойчивого результата нужны устойчивые проходы. |
| **Применение** | Числа фиксированной длины (`int32`, `int64`). | Строки разной длины, словари (лексикографический порядок). |
| **Остановка** | Всегда проходит все $d$ разрядов. | **Ранняя остановка:** если в корзине 1 элемент — выход. |

## 🌲 2. Двоичная куча (Binary Heap)

Почти полное бинарное дерево, уложенное в **одномерный массив** (0-indexed).

```text
           Дерево (Min-Heap):                   Массив (0-indexed):
                 [2]                              0   1   2   3   4
                /   \                           ┌───┬───┬───┬───┬───┐
              [5]   [4]                   ──►   │ 2 │ 5 │ 4 │ 8 │ 9 │
              / \                               └───┴───┴───┴───┴───┘
            [8] [9]
```

### Формулы индексации:
* **Левый ребёнок:** `2 * i + 1`
* **Правый ребёнок:** `2 * i + 2`
* **Родитель:** `(i - 1) / 2` *(целочисленное деление)*

### Сложность операций:
* Экстремум в корне: `get_min()` для min-heap или `get_max()` для max-heap $\to$ **$O(1)$**
* `insert()` со `sift_up` $\to$ **$O(\log n)$**
* `extract_min()` со `sift_down`, удаление по известному индексу со `sift_up` **или** `sift_down` $\to$ **$O(\log n)$**
* `build_heap()` (построение из массива) $\to$ **$O(n)$**

## 💻 3. Операции кучи (исправленный код из конспекта)

### get_min / get_max — O(1)
```text
get_min():
    return heap_arr[0]
```

### delete(idx) — удаление по известному индексу — O(log n)

Для min-heap после замены последним элементом нужно выбрать направление восстановления. Для удаления корня достаточно спуска; для произвольного индекса иногда нужен подъём.

```text
delete(idx):
    require 0 <= idx < n
    swap(heap_arr[idx], heap_arr[n - 1])
    n = n - 1
    if idx == n:
        return
    if idx > 0 and heap_arr[idx] < heap_arr[(idx - 1) // 2]:
        sift_up(idx)
    else:
        sift_down(idx)

sift_down(i):
    while 2 * i + 1 < n:
        child = 2 * i + 1
        if child + 1 < n and heap_arr[child + 1] < heap_arr[child]:
            child = child + 1
        if heap_arr[i] <= heap_arr[child]:
            break
        swap(heap_arr[i], heap_arr[child])
        i = child

sift_up(i):
    while i > 0 and heap_arr[(i - 1) // 2] > heap_arr[i]:
        swap(heap_arr[(i - 1) // 2], heap_arr[i])
        i = (i - 1) // 2
```

### insert(num) — вставка элемента (sift_up) — O(log n)
```text
insert(num):
    heap_arr[n++] = num
    i = n - 1
    while i > 0 and heap_arr[(i - 1) / 2] > heap_arr[i]:
        swap(heap_arr[(i - 1) / 2], heap_arr[i])
        i = (i - 1) / 2
    // это sift_up
```
