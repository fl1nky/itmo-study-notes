## Как добавлять занятие

Каждая лекция — отдельный файл `дисциплины/<название дисциплины>/лекции/Тема (ДД.ММ.ГГГГ).md`. Список занятий предмета находится в `лекции/README.md`. Неизвестную дату не заменяем выдуманной: сначала уточняем её, затем создаём запись.

Из корня репозитория:

```powershell
python tools/new_lesson.py --course "Дискретная математика" --date 29.09.2026 --topic "Множества и операции" --kind лекция
```

Команда создаёт файл конспекта по шаблону и обновляет индекс дисциплины. Готовый файл оформляется по [структуре конспекта](СТРУКТУРА_КОНСПЕКТА.md): тема и дата, подробное изложение с выделенными важными моментами, вопросы с отдельным раскрытием каждого ответа и теоретический минимум в самом конце. Полученные лекции, аудиозаписи и расшифровки сохраняются локально в игнорируемой папке `входящие/`; на GitHub добавляется подготовленный конспект. По отдельной просьбе фотографии занятия вставляются в нужные разделы и хранятся в `лекции/изображения/ГГГГ-ММ-ДД/`. Остальные исходные записи и личный рабочий контекст остаются локальными.

## Как вести дедлайны

Все открытые сроки записываются в [ДЕДЛАЙНЫ.md](ДЕДЛАЙНЫ.md). По просьбе пользователя они сверяются с локальным рабочим реестром; его путь хранится в игнорируемом `.local-context/WORKFLOW.md`. Дату указывайте только для конкретного известного дня; расчётный ориентир пишите в колонке «Источник и уточнение». Для завершения измените статус на `DONE`, для отмены — на `CANCELLED`.

После изменения файла GitHub Actions переносит закрытые строки в [архив](архив/ДЕДЛАЙНЫ.md). Также проверка запускается ежедневно в 00:10 по Москве. Открытая задача после прошедшей даты остаётся в текущем файле и получает пометку `просрочен`: одна только дата не доказывает, что задача выполнена или уже не нужна. Статусы `TODO`, `IN_PROGRESS`, `BLOCKED` не архивируются автоматически. Архивирование можно запустить локально: `python tools/deadlines.py`.

Текущие сроки перенесены из локального контекста ИТМО. Они обновляются из рабочего каталога по просьбе пользователя; автоматической синхронизации с ним нет. Сроки нужно перепроверять в первичных источниках перед сдачей.

## Структура

```text
дисциплины/<название>/лекции/README.md          индекс занятий предмета
дисциплины/<название>/лекции/Тема (ДД.ММ.ГГГГ).md  конспект занятия
ДЕДЛАЙНЫ.md                         открытые сроки и просроченные задачи
архив/ДЕДЛАЙНЫ.md                   подтверждённо закрытые сроки
tools/new_lesson.py                 создание занятия
СТРУКТУРА_КОНСПЕКТА.md             порядок и требования к конспекту
tools/deadlines.py                  проверка и архивирование сроков
```

`.gitignore` исключает локальный контекст, входящие записи, аудио, видео и документы. На GitHub публикуются подготовленные конспекты, реестр сроков и фотографии, которые пользователь попросил приложить к занятиям.
