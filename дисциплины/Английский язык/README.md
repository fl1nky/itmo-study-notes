## Открыть карточки

На GitHub файл HTML показывается как исходный текст. Открой `Повторение.html`, нажми **Download raw file / Скачать исходный файл**, сохрани и открой его браузером. После скачивания интернет не нужен. Если скачан весь репозиторий, просто открой этот файл в папке английского.

## Один подход — один раздел

1. Прочитай 8 слов и их примеры, затем 3 фразы.
2. В карточках выбери раздел и направление **Русский → English**.
3. Сначала скажи ответ вслух, затем открой его. «Знаю» — ответил без подсказки, «Ещё раз» — нужна ещё одна попытка.
4. Незнакомые карточки вернутся в следующем круге. Позже повтори знакомые в обратном направлении.

Управление: **Пробел** — показать ответ, **1** — знаю, **2** — ещё раз. Отметки сохраняются в этом браузере, без аккаунта и синхронизации. Короткий подход занимает примерно 5–10 минут; повтор — 3–5 минут. Это ориентир, а не обязательный темп.
