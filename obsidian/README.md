## Открыть в Obsidian

1. На странице репозитория нажми **Code → Download ZIP** и распакуй архив. Либо клонируй репозиторий через Git.
2. Установи [Obsidian](https://obsidian.md/download), открой меню хранилищ и выбери **Open folder as vault / Открыть папку как хранилище**.
3. Выбери именно папку **obsidian** внутри скачанного репозитория.
4. Открой `00_Hubs/🧭 Главная.md`. Включи режим чтения кнопкой книги в заметке; **Ctrl + G** откроет граф связей.

Для оформления достаточно встроенных возможностей: светлая тема, отступы и цвета графа уже настроены. Если оформление не применилось, в настройках **Appearance → CSS snippets** включи `study`. Сторонние плагины не нужны. Настройки скрытой папки `.obsidian` должны остаться в скачанной папке.

Без установки приложения открывай ссылки из таблицы прямо на GitHub: они используют обычный Markdown.

Чтобы получать обновления при работе через Git, закрой Obsidian, затем обнови свою копию репозитория; свои незакоммиченные заметки сначала сохрани отдельным коммитом. ZIP — разовый снимок и сам не обновляется.

Порядок открытия соответствует [официальной справке Obsidian](https://obsidian.md/help/manage-vaults); Markdown-ссылки поддерживаются [в обоих форматах просмотра](https://obsidian.md/help/links). Проверено 20.10.2026.
