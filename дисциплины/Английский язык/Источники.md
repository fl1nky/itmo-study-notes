# Источники и принципы словаря

Проверено **20.10.2026**. Формат сцен, примеры и диалоги созданы для этого учебного каталога. Переводы передают выбранный смысл; полные определения и другие значения ищи в словарях. Материал не задаёт программу преподавателя и не подтверждает освоение темы.

## Как устроены записи

| Источник | Что взято за основу |
|---|---|
| [British Council: Ten ways to learn new words](https://www.britishcouncil.org/voices-magazine/ten-ways-learn-new-words-language-learner) | Личный контекст, сочетания слов, короткие диалоги и возвращение к материалу через время |
| [British Council: Phrasal verbs](https://learnenglish.britishcouncil.org/free-resources/grammar/b1-b2/phrasal-verbs) | Порядок объекта и местоимения, разделяемые и неразделяемые конструкции |
| [Cambridge: run into](https://dictionary.cambridge.org/dictionary/english/run-into) | Значение столкновения с проблемой |
| [Oxford: narrow down](https://www.oxfordlearnersdictionaries.com/definition/english/narrow-down) | Сужение набора вариантов |
| [Cambridge: scale up](https://dictionary.cambridge.org/us/dictionary/english/scale-up) | Увеличение масштаба |
| [Cambridge: follow up](https://dictionary.cambridge.org/us/dictionary/english/follow-up) | Дополнительные действия по ранее начатому вопросу |
| [Cambridge: pick up, learn](https://dictionary.cambridge.org/us/dictionary/english/pick-up?topic=knowing-and-learning) | Освоение через практику |
| [ABC Education: back up](https://www.abc.net.au/education/learn-english/phrasal-verbs-with-back/11473878) | Резервное копирование как одно из значений связки |

В глагольных записях описано применение в конкретной сцене. Связки с несколькими значениями проверяй вместе с примером, особенно **break down**, **pick up**, **hook up**. Реплики про код являются авторскими примерами применения.
