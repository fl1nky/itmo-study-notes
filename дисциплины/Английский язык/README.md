## Начни с одного разговора

Открой первую тему, выбери 3–4 связки и разыграй мини-диалог. Потом сделай задания «Твой ход» и запиши свою реплику. Переходи к следующей теме, когда можешь использовать эти связки без постоянной подсказки.

**Тренажёр:** на GitHub открой `Повторение.html`, скачай через **Download raw file** и запусти в браузере. Выбери тему, слова/глаголы/фразы и режим: перевод или пропуск. Файл работает без интернета. Старые отметки стартового минимума сохраняются в том же браузере, если он использует то же хранилище данных для файла; перенос файла или смена браузера может дать отдельное хранилище.

| Небольшой подход | Ориентир |
|---|---|
| Разобрать одну сцену | 10–15 минут |
| Заполнить одну запись своим примером | 3–5 минут |
| Повторить знакомую тему | 3–5 минут |

Это авторская учебная подборка, а не требования преподавателя. Наличие материала и отметки тренажёра не подтверждают освоение.
