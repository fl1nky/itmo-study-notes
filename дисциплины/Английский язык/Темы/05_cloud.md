# ☁️ Релиз пошёл не по плану

> **Ситуация:** После выпуска новой версии начался сбой. Нужно обсудить откат и ресурсы сервиса.

**Твоя цель:** Сообщить о состоянии релиза и предложить следующий шаг.

## 1. Набор для разговора

Учи выражение из средней колонки целиком; затем подставь свои данные.

| Слово / термин | Готовая связка | Смысл здесь |
|---|---|---|
| **deployment** | a production deployment | развёртывание приложения или новой версии |
| **container** | run in a container | контейнер: изолированная среда для запуска приложения |
| **instance** | restart an instance | отдельный запущенный экземпляр ресурса или приложения |
| **outage** | a service outage | период недоступности сервиса |
| **scalability** | test scalability | способность справляться с ростом нагрузки при изменении ресурсов |
| **rollback** | perform a rollback | откат к предыдущему состоянию |

## 2. Фразовые глаголы в действии

### roll out — выпустить; внедрить

**Схема:** `roll something out`<br>
**Формы:** roll — rolled — rolled<br>
**Порядок слов:** Разделяется; с it: roll it out.

> We rolled out the new version this morning.

Мы выпустили новую версию сегодня утром.

### roll back — откатить к предыдущей версии или состоянию

**Схема:** `roll something back to something`<br>
**Формы:** roll — rolled — rolled<br>
**Порядок слов:** Разделяется; с it: roll it back.

> We may need to roll the release back.

Возможно, нам придётся откатить релиз.

### scale up — увеличить масштаб или ресурсы

**Схема:** `scale something up`<br>
**Формы:** scale — scaled — scaled<br>
**Порядок слов:** Разделяется; с it: scale it up. В этом примере увеличиваем ресурсы одного экземпляра.

> We scaled the instance up to give it more memory.

Мы увеличили ресурсы экземпляра, добавив ему памяти.

## 3. Две готовые реплики

> The service is currently unavailable.

Сервис сейчас недоступен.

> We can roll back to the previous version.

Мы можем откатиться к предыдущей версии.

## 4. Мини-диалог

**A:** The outage started after the deployment.<br>
**B:** Can we roll back to the previous version?<br>
**A:** Yes. We rolled the update out to one instance first.<br>
**B:** Let's roll it back and check the logs.<br>

<details>
<summary>Перевод диалога</summary>

A: Сервис стал недоступен после развёртывания. B: Можем откатиться к прошлой версии? A: Да. Сначала мы выпустили обновление только на одном экземпляре. B: Откатим его и проверим журналы.

</details>

## 5. Тонкость, которая пригодится

Rollback — существительное, roll back — глагольная связка. Outage означает недоступность; медленная работа ещё не обязательно outage. Увеличение ресурсов — один из способов масштабирования.
