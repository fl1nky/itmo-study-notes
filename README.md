## Как добавлять занятие

Для каждой лекции создаётся папка вида `дисциплины/<код>/лекции/ГГГГ-ММ-ДД (Тема)/`. Внутри лежит `конспект.md`, а рядом — презентации, PDF и другие материалы этого занятия. Неизвестную дату не заменяем выдуманной: сначала уточняем её, затем создаём запись.

Из корня репозитория:

```powershell
python tools/new_lesson.py --course dm --date 2026-09-29 --topic "Множества и операции" --kind лекция
```

Команда создаёт папку, шаблон конспекта и обновляет индекс дисциплины. В конспекте есть раздел «Главы и вопросы» — при необходимости разбивайте материал на главы прямо там. Исходные файлы можно положить рядом с конспектом; название папки и дата остаются общими для занятия.

## Как вести дедлайны

Все открытые сроки записываются в [ДЕДЛАЙНЫ.md](ДЕДЛАЙНЫ.md). Редактируйте таблицу прямо на GitHub: дату указывайте только если она подтверждена; иначе пишите `неизвестна` и объясняйте ориентир в колонке «Источник и уточнение». Для завершения измените статус на `DONE`, для отмены — на `CANCELLED`.

После изменения файла GitHub Actions переносит закрытые строки в [архив](архив/ДЕДЛАЙНЫ.md). Также проверка запускается ежедневно в 00:10 по Москве. Открытая задача после прошедшей даты остаётся в текущем файле и получает пометку `просрочен`: одна только дата не доказывает, что задача выполнена или уже не нужна. Статусы `TODO`, `IN_PROGRESS`, `BLOCKED` не архивируются автоматически. Архивирование можно запустить локально: `python tools/deadlines.py`.

Текущие сроки перенесены из локального контекста ИТМО. Их нужно перепроверять в первичных источниках перед сдачей: здесь не запускается синхронизация с учебной платформой.

## Структура

```text
дисциплины/<код>/README.md          индекс занятий предмета
дисциплины/<код>/лекции/            занятия по дате и теме
ДЕДЛАЙНЫ.md                         открытые сроки и просроченные задачи
архив/ДЕДЛАЙНЫ.md                   подтверждённо закрытые сроки
tools/new_lesson.py                 создание занятия
tools/deadlines.py                  проверка и архивирование сроков
```

Репозиторий задуман как личный: перед загрузкой преподавательских материалов проверьте, можно ли их распространять. Для больших файлов удобнее оставить ссылку на источник.
